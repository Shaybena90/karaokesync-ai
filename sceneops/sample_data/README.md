# sample_data

התיקייה `evidence/` נוצרת אוטומטית בהתקנה (`scripts\setup.ps1` / `python -m app.seed`) ומכילה
**מדיית CCTV סינתטית** שנוצרה באמצעות FFmpeg: רקע, "רכב" נע ושעון על המסך, עם הסימון SIMULATION.

הסט כולל בכוונה:
- פער הקלטה של דקה ב-CAM 01 (22:02–22:03) – לבדיקת זיהוי פערים.
- אי-התאמה של 7 דקות בין זמן שם הקובץ לזמן המטא-דאטה ב-`CAM03_20250125_220100.mp4`.
- מקטעי תנועה ידועים מראש – לבדיקת ניתוח התנועה.

אין בתיקייה ראיות אמיתיות או מידע אישי.
