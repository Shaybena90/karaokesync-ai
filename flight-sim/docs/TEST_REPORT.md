2. גאומטריית הזנב אפשרה מגע בזווית של 9° בלבד; תוקן לכ־14.7°.
3. קפיצה קצרה בגלגול ההמראה נרשמה כנחיתה, ושיבשה את ציון המשימה. נוסף סינון: המראה נחשבת כזו רק אחרי שנייה באוויר. נוספה בדיקת רגרסיה.

6. תנודת זווית התקפה בגישה הסופית (סטיית תקן 2.2°) ירדה ל־0.77° אחרי פיצול הגבר בין הגישה לבין ה־flare.
