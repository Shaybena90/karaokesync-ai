# בדיקות — KaraokeSync AI

## 1. בדיקות אוטומטיות

| מה | פקודה (מתוך התיקייה) | מה נבדק |
|---|---|---|
| שרת (Python) | `server`: ‏`.venv\Scripts\python -m pytest -q` | API, הרשאות, מכסות, בדיקת קבצים, SRT/LRC/ASS, רינדור וידאו (כולל בדיקת פיקסלים לעברית) |
| אתר (יחידה) | `web`: ‏`npm test` | סנכרון, שעון האודיו, עריכה, עיצוב, בדיקת קבצים |
| מסד נתונים | `supabase/tests/run.sh` (לינוקס / CI) | תור העבודות, RLS, שמירת כתוביות, תור הייצוא |
| **דפדפן (E2E)** | `web`: ‏`npx playwright install chromium` (פעם אחת), ואז `npm run e2e` | כל המסכים על 7 פרופילי מכשירים — ראו למטה |

הבדיקות בדפדפן לא צריכות Supabase או שרת: הן מדמות אותם בתוך הדפדפן, ומריצות את האתר בגרסת production (כולל Service Worker).

### פרופילי המכשירים בבדיקות הדפדפן

| שם | מסך | מה מדמה |
|---|---|---|
| desktop | ‏1366×860 | מחשב |
| iphone-se | ‏320×568 | הטלפון הצר ביותר (מקרה קיצון) |
| iphone-15-pro-max | ‏430×739 | אייפון גדול |
| pixel-7 | ‏412×839 | אנדרואיד |
| galaxy-s8 | ‏360×740 | אנדרואיד צר |
| ipad-mini | ‏768×1024 | טאבלט |
| phone-landscape | ‏863×360 | טלפון לרוחב |

בכל פרופיל נבדקים: אין גלילה הצידה, כל כפתור גדול מספיק לאצבע (לפחות 32px; הכפתורים הראשיים 44–72px), שדות טקסט בגודל 16px לפחות (אחרת אייפון עושה זום בזמן הקלדה), ותהליכים מלאים — העלאה, נגן (סנכרון, קפיצה, מסך מלא), עורך (כולל **גרירה באצבע** של מילה בגל הקול), עיצוב וייצוא, נגישות (axe) והתקנה כ-PWA ועבודה ללא אינטרנט.

> ⚠️ **מגבלה חשובה:** כל הפרופילים רצים על מנוע Chromium עם גודל מסך, צפיפות פיקסלים, מגע ו-User-Agent של המכשיר. זה תופס בעיות פריסה ומגע, אבל **זה לא Safari אמיתי**. לכן צריך גם את הבדיקה הידנית הקצרה למטה, על מכשירים אמיתיים.

## 2. בדיקה ידנית על טלפון אמיתי (כ-15 דקות)

איך לפתוח את האתר בטלפון: ראו "לפתוח מהטלפון באותה רשת Wi-Fi" ב-README. בדיקות PWA (התקנה) דורשות HTTPS — אותן עושים אחרי הפריסה (שלב 10) או עם תצוגה מקדימה של Vercel.

סמנו ✅ / ❌ ושלחו לי כל ❌ עם צילום מסך ודגם הטלפון.

### אייפון (Safari)
- [ ] מסך הבית: הכותרת והכפתורים לא חתוכים, אין גלילה הצידה.
- [ ] בחירת קובץ: "בחרו קובץ" פותח את אפליקציית "קבצים", ואפשר לבחור MP3 / M4A.
- [ ] בזמן ההעלאה רואים התקדמות, ובסוף עוברים לדף הפרויקט.
- [ ] הקלדה בשדה אימייל / סיסמה / מילה בעורך **לא** גורמת לזום של הדף.
- [ ] נגן: ▶ מתחיל לנגן (בלחיצה הראשונה), המילים מודגשות בזמן הנכון.
- [ ] נגן: גרירה בפס ההתקדמות — הכתוביות מתעדכנות מיד.
- [ ] נגן: "מסך מלא" ממלא את כל המסך (באייפון זה מסך מלא "רך" — הסרגל של Safari עשוי להישאר), ✕ / Esc מחזיר.
- [ ] נגן: כשהמסך כבוי / ממסך הנעילה — מופיעים כפתורי ניגון/השהיה עם שם השיר.
- [ ] עורך: לחיצה על מילה פותחת חלונית מלמטה; היא לא מכסה את המקלדת בזמן הקלדה.
- [ ] עורך: גרירת מלבן בגל הקול באצבע מזיזה את המילה, וגלילה של גל הקול הצידה עדיין עובדת.
- [ ] עורך: ✨ (סנכרון אוטומטי) על שורה שהוקלדה ידנית — תוך פחות מדקה המילים עוברות למקום שבו הן נשמעות (ה-Worker צריך לפעול).
- [ ] עורך: 👆 (סנכרון בהקשה) — הקשה על הכפתור הגדול בתחילת כל מילה ובסוף האחרונה; התזמון מתאים למה שנשמע, גם במהירות 0.75×.
- [ ] עיצוב: הוספת GIF מונפש כרקע — מופיע מאחורי המילים בתצוגה; "לכל אורך השיר" מול טווח זמנים (גם עם "מיקום נוכחי"); בסרטון המיוצא הרקע מופיע רק בטווח וחוזר בלולאה.
- [ ] עיצוב: בחירת רקע מונפש מוכן (למשל "גלקסיה") — זז בתצוגה ונעצר בהשהיה; בסרטון המיוצא הוא רץ לכל אורך השיר, מתחת לרקעים שהועלו. הייצוא הראשון עם רקע חדש לוקח קצת יותר זמן (הציור נשמר במחשב).
- [ ] עיצוב: רקע תלת מימד (למשל "במת הופעה") — זז בתצוגה ובסרטון המיוצא, בלולאה בלי קפיצה.
- [ ] עיצוב: כתב תלת מימד "עמוק" עם צבע עומק — האותיות בולטות בתצוגה, ובסרטון נראות אותו דבר (גם עם אפקט כניסה).
- [ ] חיפוש מילים: בעמוד שיר מוכן — "חפש את המילים באינטרנט" מוצא את השיר לפי השם; התוצאה באורך השיר מסומנת; "השתמש במילים האלה וסנכרן לזמר" מעבד מחדש עם המילים. שיר שלא קיים במאגר מציג "לא נמצאו מילים".
- [ ] אתרי מילים: במסך "שיר חדש" — "אתרי המילים שלי" → מדביקים כתובת של חיפוש המילה test באתר מילים → "נוסף". חיפוש שם שיר מציג תוצאות מהאתר (עם שם האתר), "השתמש במילים האלה" ממלא את המילים; אתר שחוסם מציג קישור לחיפוש באתר. הרשימה מופיעה גם בטלפון.
- [ ] ייצוא עם פתיח: ממלאים שם שיר וזמר, מסמנים פתיח + כותרת, בוחרים מעבר (למשל "עיגול נפתח") → בסרטון: פתיח עם צליל, מעבר, כותרת בזהב, מעבר, ואז הקריוקי — המילים מתוזמנות לשיר בדיוק כמו בלי פתיח. בדקו גם 9:16 ו-1:1.
- [ ] עיצוב: סרטון MP4 כרקע מתנגן בתצוגה גם בטלפון (מושתק), ונעצר כשהשיר בהשהיה.
- [ ] נגן: "הסרת הקול של הזמר" — אחרי כמה דקות (ה-Worker במחשב) מופיע מתג "עם הזמר / בלי הזמר"; המעבר ממשיך מאותו מקום, והמילים נשארות מסונכרנות.
- [ ] ייצוא: "סרטון בלי הזמר" — בסרטון שומעים רק את המנגינה.
- [ ] העלאה: בחירת "עברית" לפני ההעלאה — המילים מזוהות בעברית גם בשיר עם הרבה מוזיקה; בחלון ה-Worker מופיע שלב "מפריד את השירה מהמוזיקה" ואחריו המתג "בלי הזמר" מוכן מיד.
- [ ] ייצוא: סרטון של שיר באורך 3–4 דקות נוצר מהר יותר מבעבר (החלון של ה-Worker מראה כמה חלקים רצים במקביל במעבד).
- [ ] הדבקת מילים: בהעלאה, או אחר כך בעמוד השיר — המילים בקריוקי זהות למה שהודבק (כולל חלוקת השורות), והתזמון תואם לשירה.
- [ ] GPU: בהפעלת ה-Worker מופיעות השורות "Whisper ...: GPU" ו-"Demucs ...: GPU" (אחרי 7-enable-gpu.bat).
- [ ] עיצוב: בחירת צבע פותחת את בוחר הצבעים של iOS.
- [ ] ייצוא: הורדת SRT שומרת קובץ בשם השיר (בעברית).
- [ ] סרטון MP4 שהורד מתנגן באפליקציית "תמונות" / "קבצים", והעברית נראית נכון.
- [ ] (אחרי פריסה ב-HTTPS) שיתוף ← "הוספה למסך הבית" — האייקון והשם נכונים, האפליקציה נפתחת בלי סרגל של Safari.
